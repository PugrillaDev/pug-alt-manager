# Security policy

## Sensitive data

Pug Alt Manager handles account cookies, passwords, refresh tokens, access tokens, and session identifiers. Never attach real account data, `.pugaltmanager` storage files, legacy `.micsaltman` files, logs containing credentials, or share codes to a public issue.

## Reporting a vulnerability

If this project is hosted on GitHub, use private vulnerability reporting when available. Otherwise, contact the maintainer privately before publishing details. Include the affected version, reproduction steps using test accounts, impact, and a proposed mitigation if known.

Do not test authentication or account-management vulnerabilities against accounts or infrastructure you do not own or have permission to use.

## Supported version

Pug Alt Manager currently supports version 1.0 on Minecraft 1.8.9 with Forge 11.15.1.2318.
